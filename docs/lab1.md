# Документация по лабораторной работе №1

## Описание

Лабораторная работа №3 посвящена решению линейных интегральных уравнений второго рода.

Уравнение имеет следующий вид:

- Для Фредгольма: $ \varphi(t) = \lambda \int_a^b K(t,s) \varphi(s) \, ds + f(t) $
- Для Вольтерра: $ \varphi(t) = \lambda \int_a^t K(t,s) \varphi(s) \, ds + f(t) $

**Вариант 12** (уравнение Вольтерра, таблица вариантов методички, стр. 31):

- $ a = 0 $, $ b = \pi $
- $ K(t, s) = 2\cos(t - s) $
- $ f(t) = t\cos(t) $, то есть
- $ \varphi(t) = \int_0^t 2\cos(t - s)\,\varphi(s)\,ds + t\cos(t) $

Реализованы два метода:

1. Метод последовательных приближений: $ \varphi_{n+1} = A \varphi_n $, останов по условию $ \max|\varphi_{n+1} - \varphi_n| < \varepsilon $.
2. Сведение к системе линейных алгебраических уравнений (СЛАУ): $ (I - Q) \varphi = f $, где квадратурная формула трапеций используется для построения матрицы Q.

## Запуск

Для запуска лабораторной работы используйте команды:

- `python lab1.py` — вариант 12 по умолчанию (Вольтерра).
- `python lab1.py 12 --n 200` — вариант 12, 200 разбиений.
- `python lab1.py 12 --save` — сохранить график в PNG-файл.

Номер варианта выбирает уравнение из таблицы вариантов методички (стр. 30–31):
варианты 1–9 — уравнение Фредгольма, 10–18 — уравнение Вольтерра.

## Проверка сходимости

Для Вольтерра оператор $A$ (или его некоторая степень) всегда сжимающий,
поэтому метод последовательных приближений сходится с любого начального
приближения. Для Фредгольма (варианты 1–9) программа дополнительно проверяет
два условия сжимаемости:

- Условие по $ C[a,b] $: $ |\lambda| \cdot M \cdot (b - a) < 1 $, где $ M = \max |K(t,s)| $.
- Условие по $ L^2[a,b] $: $ |\lambda| \cdot B < 1 $, где $ B = \sqrt{\int_a^b \int_a^b K(t,s)^2 \, ds \, dt} $,

и вычисляет спектральный радиус сеточного оператора Q.

## Методы решения

### Метод последовательных приближений

- Начальное приближение: $ \varphi_0 = f $.
- Итерация: $ \varphi_{n+1} = Q \varphi_n + f $ (строка $j$ матрицы Q для Вольтерра учитывает интеграл по $[a, t_j]$ — треугольная структура весов).
- Остановка по критерию: $ \max |\varphi_{n+1} - \varphi_n| < \varepsilon $.

### Метод сведения к СЛАУ

- Решение уравнения $ (I - Q) \varphi = f $ с помощью функции `np.linalg.solve`.
- Сравнение результатов с методом последовательных приближений.

## Точное решение (аналитическая проверка)

Для варианта 12 точное решение находится дифференцированием уравнения дважды
(правило Лейбница) и сводится к ОДУ:

$$\varphi'' - 2\varphi' + \varphi = -2\sin t, \qquad \varphi(0) = 0, \quad \varphi'(0) = 1,$$

откуда

$$\varphi(t) = e^{t} - \cos t.$$

Подстановка в исходное интегральное уравнение подтверждает это решение.
Численное решение программы при $t = \pi$ даёт $e^{\pi} - \cos\pi \approx 24.14$.

## Параметры

- `variant`: номер варианта (1–18).
- `--n`: количество разбиений отрезка (по умолчанию 100).
- `--eps`: точность итераций (по умолчанию 1e-10).
- `--save`: сохранить график в PNG-файл.

## Результаты для варианта 12

- Метод последовательных приближений сходится за ~31 итерацию ($\varepsilon = 10^{-10}$, $n = 100$).
- Совпадение с решением СЛАУ: $\max|\varphi_{\text{итер}} - \varphi_{\text{СЛАУ}}| \approx 10^{-11}$.
- Совпадение с точным решением $e^t - \cos t$ — в пределах погрешности квадратуры.
