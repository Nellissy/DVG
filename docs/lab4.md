# Лабораторная работа №4

## Тема

Решение уравнения Лапласа методом сеток.

## Вариант

14

## Уравнение

$$
\frac{\partial^2 u}{\partial x^2} + \frac{\partial^2 u}{\partial y^2} = 0
$$

## Область

- Граница Г: $(|x| + 2)(|y| + 2) = 12$ — «скруглённый ромб»
- Минимальный описанный прямоугольник: $-4 \le x \le 4$, $-4 \le y \le 4$
- Область симметрична относительно обеих осей; кривая пересекает оси в точках $(\pm 4, 0)$ и $(0, \pm 4)$ и проходит, например, через узлы $(\pm 1, \pm 2)$, $(\pm 2, \pm 1)$

## Условие на границе

$$
u|_Г = 2|x| + 0.5|y|
$$

## Сетка

- $x_m = -4 + m \cdot h$, $y_n = -4 + n \cdot h$, $h_1 = h_2 = h = 1/K$ (методичка: шаги порядка 0.1, т.е. $K = 10$)

## Криволинейная граница

В отличие от варианта с наклонными прямыми, криволинейная граница НЕ проходит
через узлы сетки. По указанию методички («определить значения искомой функции
u в граничных узлах с возможно меньшей погрешностью») реализовано следующее:

1. **Граничные узлы** — внутренние узлы области, у которых хотя бы один сосед
   (по 4 направлениям) лежит вне области, т.е. узлы, ближайшие к границе.
2. **Значение в граничном узле** берётся из граничного условия в ближайшей
   точке кривой: узел проецируется на границу (грубый минимум по плотной
   выборке точек кривой + уточнение золотым сечением), затем вычисляется
   $u = 2|x| + 0.5|y|$ в точке проекции.
3. Проверка: максимальное расстояние от граничного узла до кривой не
   превышает $h/2$ (при $K = 10$ оно равно ~0.076 < 0.1).

Кривая задаётся в полярных координатах: $(r|\cos\theta| + 2)(r|\sin\theta| + 2) = 12$, откуда
$r(\theta) = \dfrac{16}{2(a+b) + \sqrt{4(a+b)^2 + 32ab}}$, $a = |\cos\theta|$, $b = |\sin\theta|$ (устойчивая форма).

## Разностное уравнение

$$
u[m,n] = \frac{1}{4}(u[m-1,n] + u[m+1,n] + u[m,n-1] + u[m,n+1])
$$

записывается во всех внутренних узлах; граничные узлы участвуют в правой части как известные значения.

## Методы решения

- Метод Зейделя (новые значения используются сразу; обход по столбцам)
- Метод наискорейшего спуска (для $A u = b$, $A$ — сеточный оператор Лапласа: симметричный, положительно определённый)

## Запуск

- `python lab4.py` — параметры спрашиваются (по умолчанию K = 10)
- `python lab4.py <метод> <K>` — например: `python lab4.py 1 10`
  - метод: 1 — Зейдель, 2 — наискорейший спуск
  - $K = 1/h$: $K=10 \to h=0.1$ (как в методичке), $K=5 \to h=0.2$ (быстрее)

## Результаты (метод Зейделя, K = 10, h = 0.1)

- Узлов: внутренних 1901, граничных 196
- Сходимость итераций: 2233 итераций (~0.5 с), критерий $\max|u_{new} - u_{old}| < 10^{-8}$
- Проверка принципа максимума
- Проверка невязки разностного уравнения
- Отличие от прямого решения той же системы (scipy, если установлен)

## Принцип максимума

- Значения внутри области находятся в пределах значений на границе:
  $u \in [2.0592,\ 7.4713]$ при граничных $[2.0000,\ 8.0000]$ — выполнен
- Решение симметрично относительно обеих осей: $u(x, y) = u(-x, y) = u(x, -y)$
  (область и граничная функция симметричны)

## Невязка разностного уравнения

- Максимальная невязка: $\max|\text{сумма соседей} - 4u| \approx 2.0 \cdot 10^{-8}$

## Отличие от прямого решения

- Отличие от прямого решения той же разностной системы (sparse solve): $1.75 \cdot 10^{-6}$

## Графики

- Решение $u(x, y)$ (изолинии + заливка, красным — граница Г)
- Сходимость: $\max|u_{\text{new}} - u_{\text{old}}|$ по итерациям (полулог. шкала)

## Дополнительные параметры

- Шаги $h_1 = h_2 = h = 1/K$
- Узлы вне области обозначаются точкой в таблице значений

## Точность метода

- Граничные значения переносятся с погрешностью $O(h)$ (положение граничного узла относительно кривой), поэтому суммарная погрешность имеет первый порядок по $h$
- Точное решение неизвестно, поэтому погрешность оценивается сравнением решений при K = 10 и K = 20 в общих узлах: максимальное различие в «ядре» области ~0.017, в среднем ~0.004 (уменьшение при $h \to h/2$ подтверждает сходимость)

## Примечания

- При решении используется метод сеток с итерационными методами
- Значения внутри области лежат между минимумом и максимумом граничных значений (принцип максимума)
- Принцип максимума — необходимое условие корректности решения (но не доказательство его точности)
- Невязка разностного уравнения показывает, насколько точно решена сеточная система; она определяется критерием остановки ε = 10⁻⁸
- Отличие от прямого решения (sparse solve) показывает итерационную погрешность; оно должно быть порядка ε/(1−ρ) и не отражает погрешность самой разностной схемы
